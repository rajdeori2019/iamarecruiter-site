Reusable recruiter resource

TALENT INTELLIGENCE
PROMPT SHEET

Use these prompts with one live hiring role. Replace bracketed sections with real information. Do not use AI output as verified market evidence until you check it.

Permanent rule: Facts must come from the role information or reliable evidence you provide. Inference, assumption and unknown must stay labelled. Missing evidence = “Unknown — requires verification.”
01 · Requirement

Hiring Requirement Diagnostic

Use before sourcing to clarify what the business is actually asking for.

ROLE You are supporting a recruiter before sourcing begins. TASK Diagnose the hiring requirement below. Do not invent market facts, candidate counts, salaries or company data. REQUIREMENT [PASTE ROLE / JD / HM NOTES] OUTPUT 1. Confirmed requirements 2. Assumptions being treated as requirements 3. Missing information 4. Ambiguities / contradictions 5. Requirements that may unnecessarily narrow the search 6. Must-have vs nice-to-have recommendation 7. Questions to ask the hiring manager 8. Suggested search lane(s) EVIDENCE RULE For every conclusion, point back to the requirement text where possible. If unsupported, label it “Unknown — requires verification.”
02 · Search

Search Architecture Builder

Turn the calibrated requirement into practical search lanes.

ROLE You are a recruiter search-architecture assistant. TASK Use only the calibrated hiring requirement below. Do not execute searches or invent market data. REQUIREMENT [PASTE CALIBRATED REQUIREMENT] OUTPUT 1. Primary job titles 2. Adjacent / equivalent titles 3. Must-have keywords 4. Skill synonyms / variants 5. Transferable skills 6. Likely exclusions / noise terms 7. Direct-fit search lane 8. Adjacent-fit search lane 9. LinkedIn keyword logic 10. Google X-Ray logic 11. Naukri / Resdex logic where relevant Label any non-stated title or skill interpretation as inference.
03 · Evidence

Talent Supply Evidence Interpreter

Interpret only what you actually observed in sourcing tools.

ROLE You are analysing recruiter-supplied talent-market evidence. EVIDENCE [PASTE PLATFORM, DATE, LOCATION, EXACT SEARCH / FILTERS, OBSERVED COUNT IF SHOWN, QUALITY / NOISE NOTES] TASK Analyse only the evidence above. Do not generate additional candidate counts or claim market facts not present in the evidence. OUTPUT 1. Verified observations 2. Directional signals 3. Search-quality issues 4. Potentially narrowing filters 5. Alternative search lanes worth testing 6. Evidence still missing RULE Do not conclude that the market is easy or hard from a raw result count alone.
04 · Companies

Target Company Mapper

Create research candidates, not invented “verified” source companies.

TASK Build a target-company research framework for this hiring requirement. REQUIREMENT [PASTE REQUIREMENT] OUTPUT Tier 1 — Direct fit Tier 2 — Adjacent fit Tier 3 — Alternative pool For each company include: - Why it may be relevant - Which requirement / lane it maps to - What must be verified - Evidence / source if available RULES If reliable current evidence is unavailable, label the company as a Research Candidate, not a verified source company. Never invent company facts, hiring activity, tech stacks, locations or talent availability.
05 · Compensation

Compensation Evidence Interpreter

Use only comparable compensation evidence.

TASK Analyse the compensation evidence below. HIRING BUDGET [PASTE BUDGET] EVIDENCE [PASTE SOURCE, ROLE, LOCATION, EXPERIENCE, RANGE / CTC, DATE, LIMITATIONS] OUTPUT 1. Verified evidence 2. Directional interpretation 3. Comparability limitations 4. Budget assessment: Appears aligned / May constrain hiring / Not directly comparable / Insufficient evidence 5. What should be discussed with the hiring manager RULE Do not invent a “market salary” or average incompatible observations.
06 · Advisory

Hiring Manager Advisory Builder

Turn validated evidence into an HM-ready recommendation.

ROLE You are helping a recruiter prepare an evidence-based hiring-manager update. INPUT [PASTE VALIDATED REQUIREMENT + TALENT SUPPLY + COMPANY + LOCATION + COMPENSATION + FEASIBILITY EVIDENCE] OUTPUT 1. Executive summary 2. Key constraints 3. Evidence → implication → recommendation → HM decision 4. Decisions required from the hiring manager 5. Recommended sourcing plan 6. Copy-paste HM advisory note RULE Use only the evidence provided. If evidence is weak or incomplete, say that clearly. Do not manufacture market conclusions to make the recommendation sound stronger.

Recruiter remains responsible for verification, business context and the final decision.
