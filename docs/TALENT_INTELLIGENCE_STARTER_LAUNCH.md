# Talent Intelligence Starter Pack — Validation Launch

## Objective
Test real demand before building more product.

## Offer
Price: ₹99 founding beta.
Audience: working recruiters, senior recruiters and TA professionals.
Core promise: help recruiters move from JD → sourcing to requirement diagnosis → search strategy → evidence → hiring-manager recommendation.

Included:
1. Talent Intelligence eBook
2. Reusable AI Prompt Sheet
3. Talent Market Snapshot beta tool
4. Existing workbook/supporting resources

## Funnel
Ad → Starter Pack landing page → Razorpay purchase → immediate access → product usage → feedback → optional cohort nurture.

Landing page:
https://www.iamarecruiter.in/talent-intelligence-starter.html

## Ad angles

### A — Sourcing too early
Hook: Most recruiters start sourcing too early.
Body: A JD lands and the first instinct is LinkedIn or Naukri. But if the requirement is unclear, a better Boolean string will not fix the search. Use one live role to diagnose the requirement, build search lanes and collect real market evidence.
CTA: Get the ₹99 Talent Intelligence Starter Pack.

### B — Strategic recruiter
Hook: Using ChatGPT does not make you a strategic recruiter.
Body: The difference is whether you can explain what the market is showing, what is still unknown and what decision the hiring manager needs to make. This starter pack gives you a practical workflow to try on one real role.
CTA: Start for ₹99.

### C — Hiring-manager credibility
Hook: What do you say when the hiring manager asks, “Why are we not finding candidates?”
Body: “I’m still sourcing” is an activity update. A stronger answer is built from requirement clarity, search evidence, market constraints and a recommendation. Try the workflow on one live role.
CTA: Get the ₹99 Starter Pack.

## Validation questions
Do not scale based on clicks alone. Track:
- Landing-page visits
- Checkout starts
- Purchases
- Cost per purchase
- Which ad angle produced the purchase
- Whether the buyer opened the resources
- Whether the buyer used the live-role tool
- Buyer usefulness feedback
- What felt confusing or unnecessary
- Whether they want deeper training/cohort support

No conversion-rate, CAC, ROAS or demand target is treated as proven until real campaign data exists.

## Build freeze rule
During the first validation cycle, do not add new modules unless a blocker prevents purchase, delivery or core usage. Prioritise real buyer feedback over further feature expansion.
